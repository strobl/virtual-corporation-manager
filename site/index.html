Structure first.
Then a concrete task.

Keep responsibilities, changes and actual work in one place. You choose when an agent starts.

  1. 01

    Give every role a job.

    Create a company from scratch or preview a software delivery template with 20 or 100 differentiated roles. Inspect departments, managers, instructions and responsibilities before applying it.

  2. 02

    Review the change.

    Navigate the company map, reporting lines and searchable agent list. Configuration changes have an exact preview, atomic apply and version-aware undo.

  3. 03

    Run. Inspect. Accept.

    Connect your optional runtime and submit an explicit task. Review the actual output, run ID, duration and hash. Accept a result when it meets your standard.

Your next company starts here

Open a terminal.
Open your company.

Use Node.js 24.14 or newer in the 24.x line. Install the alpha release, then start GitFlash.

Terminalv0.1.0-alpha.2
npm install --global "https://github.com/strobl/gitflash/releases/download/v0.1.0-alpha.2/gitflash-0.1.0-alpha.2.tgz"
gitflash

The CLI opens a loopback URL in your browser. Your workspace lives in ~/.gitflash. Downloading requires a connection; the installed core works offline.
