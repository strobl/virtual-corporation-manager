Local setup

Open VCM on your computer.

This page describes review candidate 0.1.0-alpha.3-local.4. It has not been published as a downloadable VCM release.

If you received the candidate archive for review, verify its matching handoff checksum and use the commands below. The local version alone does not identify a candidate.

Supplied review archiveNode.js 24.14+ in 24.x, or 26.x 
npm install --offline --ignore-scripts --prefix ./gitflash-preview ./gitflash-0.1.0-alpha.3-local.4.tgz
node ./gitflash-preview/node_modules/gitflash/dist/cli.js --data-dir ./my-company

Open the loopback URL printed by the CLI. The technical package and command remain gitflash. The default workspace is ~/.gitflash; the command above uses a separate folder.

Obtaining the archive requires a connection. The supplied archive installs offline, and company setup and time tracking work locally. Executing the Product Studio job uses your separately installed Codex CLI, Python and runtime access.

Looking for the existing public release?

The public v0.1.0-alpha.2 release is an older GitFlash version. It does not include the VCM entry screen, delivery-hours Time Tracker or Product Studio company file workflows shown here. Its own release notes and requirements apply.

In the installed app

A clear next step for each action.

01

Run a task

The included PS-001 Stock Alert exercise creates a Python utility for fictional Meadow Tools inventory. It does not connect to an inventory system or place orders.

Input
The included brief, acceptance criteria, synthetic inventory in input.json and a named review owner.
Output
stock_alert.py with reorder_items(products), tests, expected output, usage instructions and review evidence in a downloadable ZIP.
Next action
Open Home → Run a task. In an empty workspace, choose and review the Product Studio (5 seats) template first. Review the job form and prerequisites, then explicitly choose Start job.
Need the app? See local setup ↑
02

Review results

Keep the evidence beside the decision. A successful automated check does not accept the result for you.

Input
A completed company job or individual task in your workspace.
Output
Files and receipts to inspect, followed by your explicit acceptance or rejection with a note.
Next action
Open Home → Review results. Select the result, inspect its evidence, and download the files you want to review. If there is no result yet, start the first task.
No result yet? Start with the task guide ↑
03

Track delivery hours

Book human-equivalent delivery hours with a manual entry or a shared reference estimate. Runtime duration never creates booked hours.

Input
A company, an activity and delivery hours, or an estimate from the 124-definition reference catalog.
Output
Saved entries, corrections with history, and delivery-hours analytics.
Next action
Open Home → Track delivery hours. Create an entry, review its basis and save. Use the history and analytics views to inspect your records.
Open the local workspace ↑
04

Set up a company

Organize the people, agent roles and responsibilities that own the work. Creating or importing a company never starts inference.

Input
A company name and purpose, followed by its team or a reviewed template.
Output
A saved local organization with departments, assignments and responsibilities.
Next action
Open Home → Set up a company, review the proposed change and apply it. Organization views, search, templates and undo remain available.
For the included job, use Product Studio ↑
