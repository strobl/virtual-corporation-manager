## Art direction

The emotional idea is **ambition gets support**. The team has an active shared purpose. Vic is a builder and teammate, with the familiar rounded V silhouette, dot eyes, small smile and tiny limbs. A human remains visibly human. Tactile clay materials, soft directional shadows and playful scale create continuity with the approved Buzz campaign.

The hero uses warm cream, orange leadership, mint and yellow teammates, and a cobalt paper plane as a metaphor for giving an idea a first version. The values scene uses ink as its stage, with an open blue toolbox and code brackets to express experimentation, adaptation and sharing. Neither scene suggests autonomous execution or measurable business results.

## Page direction

1. A compact, expressive split hero: **Big ideas deserve a team.** New paper-plane artwork, direct install and explore actions, clear local/MIT facts.
2. An interactive fictional team: human direction plus Researcher, Builder and Reviewer roles. Selecting a role reveals its purpose and responsibilities. Keep the existing downloadable configuration.
3. Product proof: unchanged current Northstar Studio Alpha 9 desktop and mobile captures, original-size links and provenance. Concise company, people and responsibility benefits, with Time Tracker information nearby.
4. An illustrated ink values section: **Built for people who build.** Preserve all five values: Play 2 win; Be adaptable; Never stop hacking; Hackers first; Be open.
5. The approved Buzz campaign as a large visual invitation to the integrations page.
6. Practical installation, with exact versioned commands and a working copy action. Keep provider setup optional.
7. A confident orange closing invitation and compact footer.

Use clear HTML type, asymmetrical compositions and restrained motion to establish rhythm. Respect reduced motion, keyboard focus and mobile stacking. Keep the page useful with motion disabled. Preserve the existing domain, metadata, product facts, install requirements and integration route.

## Acceptance

- Desktop and mobile have no horizontal overflow or clipped actions.
- Role controls, navigation, download, original-size screenshot links and command copying work.
- Art files and existing product captures are served from the site and match their sources.
- Exactly one current canonical and social metadata set remains on each route.
- The refreshed native Lovable page is published and checked at the custom domain.

The native page implementation lives in the existing Lovable project; this directory is its versioned brand source.
