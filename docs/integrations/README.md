# Your team. In the conversation.

![VCM screenshot campaign based on the native Buzz team-import preview](../images/vcm-integrations.png)

Organize the corporation in VCM. Bring AI roles into Buzz.xyz or explore focused tasks from Slack. The local MIT core works independently of either connection.

| Connection   | What VCM provides                                                                                                                                     | Start here                            | Evidence boundary                                                                  |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- | ---------------------------------------------------------------------------------- |
| **Buzz.xyz** | A native `.team.json` export of active, assigned AI roles and their instructions. An optional CLI adapter dispatches tasks to mapped Buzz identities. | [Team import and task setup](buzz.md) | Historical native import in Buzz 0.5.8; live task execution remains unverified.    |
| **Slack**    | An explicitly connected Socket Mode app accepts a named-role mention from one allowed owner/channel, runs local Codex and replies in the same thread. | [App manifest and setup](slack.md)    | Adapter fixtures exist; a live mention → useful result → reply proof remains open. |

The lead graphic is an editorial composition based on the native Buzz import preview with the public three-role example. Exporting a team, authenticating a token or opening a socket does not establish completed work. [Detailed runtime contract](../integrations.md) · [Acceptance record](../acceptance.md)
