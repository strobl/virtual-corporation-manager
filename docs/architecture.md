# Architecture

GitFlash is one TypeScript application. A Node.js process serves a prebuilt React console on `127.0.0.1`. SQLite schema 5 stores companies, departments, agents, dated assignments, relationships, work, reviewed changes, runtime receipts, workflow jobs/artifact bytes and a separate delivery-hours ledger. There is no hosted database, account service, billing layer or required telemetry.

The browser reads a workspace snapshot and submits typed commands. Every configuration command is validated to produce a persisted preview at a specific workspace revision. Confirmation applies that exact preview in one transaction. Repeating confirmation is idempotent; intervening changes invalidate stale previews. Supported undo is version-aware and does not reverse an external action.

The CLI owns the selected data directory and the store owns an exclusive process lock. The HTTP boundary rejects unknown Host values, foreign origins, cross-site requests and mutation requests without a random per-process capability. The same-origin console and trusted local processes can retrieve the capability from the loopback session endpoint. This is a local process protection, not an account or multi-user permission system. LAN hosting and tunnels are outside the supported deployment model.

Creating an agent does not launch it. Optional Codex execution uses the operator's installed CLI and authenticated provider access. The individual-task route runs one read-only, text-output task at a time with at most 20 outstanding requests. The company-job route runs one bounded workflow at a time with at most three active/queued jobs; its five roles use separate workspace-write sessions sequentially. These are separate queues, so one individual task can run alongside one company workflow. Buzz and Slack remain experimental routes with separate prerequisites and incomplete live round-trip evidence.

Company jobs capture the selected company, five role identities, content version and input hashes at start. Python/sandbox preflight runs before any model dispatch. Each stage uses a fresh directory, observed session receipt and actual runtime-created UTF-8 files. The fixed independent oracle checks an exact candidate copy, then a different QA session inspects immutable candidate bytes and records its criteria. Stage/QA control records can stop the sequence; ordinary repair and explicit runtime retry each have separate limits. A complete handoff leaves the job waiting for the owner's explicit decision. Elapsed runtime and job acceptance never create delivery-hour bookings.

Workflow artifact bytes, hashes, commands, captured context and owner decisions live in SQLite. Stage directories are disposable after successful capture. Full backup/restore checks both directions of artifact ownership and the completed review chain; queued or interrupted provider work is marked failed on restart rather than silently dispatched. Configuration export deliberately contains none of this execution history.

The SQLite driver is Node's built-in `node:sqlite`, avoiding a separately compiled database addon. Package engines allow Node 24.14+ in the 24.x line and Node 26.x. CI is configured for minimum/current versions on macOS, Linux and Windows; [acceptance evidence](acceptance.md) distinguishes pending candidate runs from historical results. Native Windows supports the local core and Time Tracker, while company-workflow checking requires macOS or Linux. The [Node SQLite documentation](https://nodejs.org/api/sqlite.html) describes the upstream API.

The visual console selectively adapts the predecessor's organization layout, reporting chart and design primitives. Hosted wrappers, auth, SaaS billing and private history are excluded. See third-party notices and contribution guidance for source treatment.

The Time Tracker uses targeted SQLite writes in the same store/lock and shared revision boundary. Booking, correction/void, catalog basis, history and request receipt commit atomically. Configuration snapshot replacement never replaces the time ledger; time changes invalidate older configuration previews. Integer tenths of a human-equivalent hour drive all totals, separately from execution duration and output acceptance. See [Time Tracker](time-tracker.md).
