# Set up and manage your company

Start with [company management](../company-management.md). Create a company with a name and optional purpose, add humans and AI agents, and define their responsibilities. No template, starter team, task or runtime login is required for basic company setup.

Use the current release's [first-company guide](../../first-company.md) for installation, save review and the complete onboarding path. The [member guide](../members-and-responsibilities.md) covers member type, responsibilities, reporting, primary/shared membership and company relationships. The existing [Time Tracker](../../time-tracker.md) is unchanged; company management does not silently create booked hours.

## Optional Product Studio workflow

The [Product Studio guide](../../product-studio.md) and the [optional execution section](../../first-company.md#optional-execution) describe the specialized PS-001 stock-alert example. Choose it only when you want that workflow. Its five roles, fictional input, runtime/platform prerequisites, bounded repairs, actual QA evidence and owner decision remain specific to that job. They are not prerequisites for creating your company.

The original imported guide and the alpha.6 branding adaptation remain traceable through the original import, branding and subsequent product-adaptation receipts. This routing page changes onboarding emphasis; it does not change role prompts, authority limits, acceptance criteria, the oracle or historical outputs.

For a company, member or workflow problem, use the current [support guide](../../support.md). Keep failed or rejected outcomes intact and report only the minimum safe evidence.
